How to use this demo

1. Add volunteers in the Volunteers tab.

2. Create a service opportunity with a date, location, and capacity.

3. Register a volunteer for an opportunity in Sign-ups & hours.

4. Mark attendance and enter completed hours to update the impact dashboard.

Demo data is stored in this browser using localStorage. It is not uploaded to a server.
